# Contributing to the SciLifeLab RDM guidelines website

## Internal contribution

The RDM-guidelines repository has an editorial group consisting of members of SciLifeLab's Data Centre and NBIS data management teams. For the contribution process to be followed by the editorial group, please see: https://github.com/ScilifelabDataCentre/RDM-guidelines/blob/main/internal-contribution.md. 

## External contribution

We welcome feedback to the content of this site from Swedish life science researchers and RDM support providers. For the contribution process to be followed by this group, please see: https://github.com/ScilifelabDataCentre/RDM-guidelines/blob/main/external-contribution.md.
